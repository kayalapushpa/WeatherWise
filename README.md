🌦️ WeatherWise

WeatherWise is a user-friendly weather application that allows users to search for a city and view useful weather information such as temperature, humidity, wind speed, and current weather conditions.

✨ Features

- 🔍 Search weather by city
- 🌡️ Display temperature
- 💧 Show humidity
- 💨 Display wind speed
- 🌤️ Show weather conditions
- 📅 Display basic weather details
- 📱 Responsive and simple interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Weather API

📂 Project Structure

WeatherWise/
│
├── index.html

├── script.js

🚀 How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Add a valid weather API key in "script.js".
4. Open "index.html" in a web browser.
5. Enter a city name to view its weather information.
